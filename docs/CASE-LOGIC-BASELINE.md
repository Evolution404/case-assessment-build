# 案例逻辑基准：外协队伍“增效 + 提质”数智管理

> 本文件是本案例报告、答辩PPT、逐字稿和配图的最高优先级内容基准。后续修改如与本文件冲突，以本文件为准。

## 1. 案例唯一主语

**输电运检外协队伍管理。**

本案例不是“空间分析案例”，也不是“照片查重案例”。空间计算、鸟类活动数据、照片查重算法等均为解决外协管理问题的数字化手段，不能取代外协管理成为叙事主线。

## 2. 两大管理痛点

### 痛点一：工作量大

输电线路点多、线长、面广，交叉跨越、防鸟、集中燃放点等专项台账和风险对象数量大。传统方式依靠外协人员全量摸排、逐项核验，存在排查范围大、重复劳动多、无效投入高等问题。

### 痛点二：质量难保证

外协巡视、告警处置等工作产生海量照片，管理人员不可能逐张检查。传统人工抽查覆盖有限，难以全面发现历史照片复用、重复上传、处理后再次上传等问题，外协履职真实性和工作质量缺少全量监督手段。

## 3. 两条解决主线

### 主线A：增效——解决“工作量大”

核心问题：**外协人员到底需要去哪里、查什么？**

管理方式：

**全量人工排查 → 系统自动筛选 → 形成候选清单 → 外协精准核验 → 结果回写闭环**

典型数字化方案：

1. 交叉跨越自动筛查；
2. 鸟类活动重点区域与输电线路空间叠加筛查；
3. 集中燃放点周边线路、杆塔缓冲筛查；
4. 后续可扩展到其他专项台账、空间关系和风险对象自动筛选。

三个现有场景的共同价值不是展示三种算法，而是：**减少外协无效排查，把“到处找”变成“按清单精准查”。**

### 主线B：提质——解决“质量难保证”

核心问题：**外协人员是否真实、认真完成了工作？**

管理方式：

**有限人工抽查 → 照片全量查重 → 异常候选生成 → 管理人员重点复核 → 质量问题闭环**

典型数字化方案：

1. 告警工单照片查重：从0到1建立外协作业成果真实性核查能力；
2. 巡视照片查重：从少量特高压扩展到全电压等级、每月1245万张，形成常态化规模监督能力。

照片查重的核心价值不是展示 pHash、CLIP，而是：**把外协质量监督从“有限抽查”升级为“全量监督”。**

## 5. 两条主线的统一方法论

两条主线表面上处理不同对象，底层管理机制一致：

- 增效：**全部任务 → 机器筛选 → 人工核验**；
- 提质：**全部照片 → 机器筛选 → 人工核验**。

统一原则：

**机器负责全量筛选和重复劳动，人员负责专业判断、现场核验和管理责任。**

## 6. 技术内容的正确位置

技术只能作为“如何实现”的支撑层出现。三个空间专项统一按“点—线—面”理解：交叉跨越对应线，防鸟对应面，集中燃放点对应点。

- 交叉跨越（线）：包围盒预筛 + Shapely精确几何求交；
- 防鸟（面）：GBIF鸟类发生记录空间聚合 + 输电线路叠加，周边生态环境用于业务复核；
- 集中燃放点（点）：低成本范围预筛 + 燃放点—杆塔距离判断 + 涉及线路汇总；
- 照片查重：pHash汉明距离快速召回 + CLIP相似度复核 + 分批处理 + 断点续算 + 人工终审。

技术章节必须先回答“解决了什么外协管理问题”，再解释算法，不能从算法直接起笔。

## 7. 报告建议章节

1. **背景：外协队伍成为输电运检的重要力量**
2. **问题：外协管理面临“工作量大、质量难保证”两大痛点**
3. **思路：构建“增效 + 提质”的外协数智管理模式**
4. **做法一——增效：数字化筛选减少外协无效排查**
   - 交叉跨越
   - 防鸟
   - 集中燃放点
5. **做法二——提质：照片查重强化外协履职质量监督**
   - 告警工单照片查重，从0到1
   - pHash + CLIP 双阶段候选生成
   - 巡视照片查重，从小范围扩展到全电压等级
   - 千万级工程化处理
6. **实施效果**
   - 全量排查 → 精准核验
   - 有限抽查 → 全量监督
   - 人海式管理 → 数智协同管理
7. **推广应用：形成可复制的外协数智管理机制**

## 8. 固定核心表述

推荐总述：

> 针对输电运检外协队伍“工作量大、质量难保证”两类管理痛点，以数字化手段一方面提升任务筛查效率，另一方面强化作业质量监督，实现外协管理由“人海式管理”向“数智协同管理”转变。

推荐结论：

> **增效管任务，提质管履职。** 增效让外协人员从全量人工排查转向系统筛选、精准核验；提质让外协履职质量从有限人工抽查转向照片全量查重、异常重点复核。
