# 江苏省公开集中/疏导燃放点数据审计（2026-09-01）

## 1. 使用口径

本数据用于案例报告“集中燃放点周边杆塔筛查”方法展示，目标不是制作烟花燃放导航图，而是建立一个**可追溯、不可模拟、可重复生成**的省域公开点位输入集。

- 审计范围：江苏省13个设区市。
- 时间范围：优先采用2026年春节公开资料；仅无锡因未检索到2026年同等完整的市级文字点位清单，保留最新完整官方2025年10点名单并明确标注年份。
- 纳入条件：政府、公安、应急管理部门或可明确追溯到相关部门的权威媒体公开确认该地点属于集中、定点、疏导或群众自发聚集燃放点；同时能够形成省域制图近似坐标。
- 排除条件：仅有禁限放范围、仅有烟花秀商业活动、无法独立确认的社交媒体点位、仅能猜测的位置。
- 禁止规则：某市未找到可落图点位时，记录为“已审计但未发现可独立落图清单”，**不得随机生成、不得按城市中心补点、不得用烟花销售点替代燃放点**。
- 坐标口径：WGS84。部分点位依据公开道路、街镇、官方示意图或公开POI近似定位。500米缓冲结果仅用于案例空间筛查方法展示，不作为现场作业、执法或导航坐标。

正式数据文件：`data/fireworks_jiangsu_verified.json`。

## 4. 坐标核验说明

- 行政区、道路、公开POI坐标优先通过正式江苏OSM PBF或公开地理编码进行交叉核验。
- 对仅公布街镇或道路区段、未公布精确经纬度的点位，采用公开位置的近似中心坐标，并在JSON的 `coordinate_precision` 字段中明确标注。
- 对需要从GCJ-02公开地图位置辅助核验的POI，转换到WGS84后才写入正式数据集；不得把GCJ-02坐标直接与正式WGS84杆塔库混用。
- 不在报告图中显示具体名称、坐标或导航信息。

## 5. 后续更新规则

若后续发现2026年官方新增完整点位名单，应：

1. 先在本文件补充来源和审计说明；
2. 更新 `data/fireworks_jiangsu_verified.json`；
3. 保留 `reference_year` 和 `coordinate_precision`；
4. 重新运行正式空间图生成器；
5. 不允许以旧点位静默覆盖新年份，也不允许为补齐数量而生成模拟点。
